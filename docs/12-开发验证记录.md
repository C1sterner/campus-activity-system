接口测试脚本读取本地demo验证码图中的数字，使用隔离TEST_账号，不涉及第三方登录验证码。数据库测试使用新建的隔离目录与数据库，未访问既有MySQL业务库。

执行命令：

```powershell
# backend目录
.\mvnw.cmd test

# 仓库根目录，服务已在本机demo模式启动
python scripts/smoke-test.py --url http://127.0.0.1:8080
```

真实MySQL集成测试须先新建专用空库，设置`TEST_DB_URL`、`TEST_DB_USER`、`TEST_DB_PASSWORD`，然后在backend目录执行：

```powershell
.\mvnw.cmd "-Dtest=CampusIntegrationTest" "-Dspring.profiles.active=mysql" test
```

集成测试会清空专用测试库内的相关业务表并重建夹具，严禁指向真实用户数据库。大规模性能、长期可用性、全浏览器兼容与生产部署未验证；当前限制详见使用说明。
